---

## 🌐 What are Networking Devices?

Networking devices are hardware components that help computers, servers, and other devices **connect and communicate with each other** over a network.

Some common networking devices are:

- Router
- Switch
- Firewall
- Server
- Access Point
- Hub

---

# 1. 📡 Router

A **Router** is a networking device that connects **different networks** and forwards data packets between them.

### Main Functions

- Connects different networks
- Forwards packets between networks
- Determines the path for data
- Connects local networks to the Internet
- Can provide services such as NAT and DHCP

### Example

A home router connects your local home network to your Internet Service Provider (ISP).

### Remember

> **Router → Connects different networks**

---

# 2. 🔀 Switch

A **Switch** connects multiple devices within a **Local Area Network (LAN)**.

It uses **MAC addresses** to forward Ethernet frames to the appropriate device.

### Main Functions

- Connects computers and other devices in a LAN
- Forwards Ethernet frames
- Learns MAC addresses
- Uses a MAC address table for forwarding decisions

### Example

In an office, multiple computers can connect to a switch to communicate with each other and access network resources.

### Remember

> **Switch → Connects devices within a LAN**

---

# 3. 🔥 Firewall

A **Firewall** is a security device or software system that monitors and controls network traffic according to predefined security rules.

### Main Functions

- Filters incoming and outgoing traffic
- Blocks unauthorized connections
- Allows legitimate traffic
- Helps protect networks from threats
- Controls network access

### Example

A company can use a firewall to prevent unauthorized Internet traffic from reaching its internal network.

### Remember

> **Firewall → Protects and controls network traffic**

---

# 4. 🖥️ Server

A **Server** is a computer or system that provides services, applications, data, or resources to other devices called clients.

### Common Types of Servers

- Web Server
- File Server
- Database Server
- DNS Server
- DHCP Server
- Mail Server

### Example

When you visit a website, your browser communicates with a web server to retrieve the website's content.

### Remember

> **Server → Provides services and resources**

---

# 5. 📶 Access Point

An **Access Point (AP)** provides wireless connectivity and allows Wi-Fi devices to connect to a network.

### Main Functions

- Provides Wi-Fi connectivity
- Connects wireless devices to a network
- Extends wireless network coverage
- Allows laptops, smartphones, and other devices to access network resources

### Example

A university can use multiple access points to provide Wi-Fi coverage across classrooms and buildings.

### Remember

> **Access Point → Provides wireless network access**

---

# 6. 🔌 Hub

A **Hub** is a basic networking device that connects multiple devices.

When a hub receives data, it broadcasts the data to all connected ports.

### Important Point

Hubs are largely outdated and have been replaced by switches in modern Ethernet networks.

### Remember

> **Hub → Broadcasts data to connected ports**

---

# 🧠 Quick Comparison

| Device | Main Purpose |
|---|---|
| Router | Connects different networks |
| Switch | Connects devices within a LAN |
| Firewall | Filters and protects network traffic |
| Server | Provides services and resources |
| Access Point | Provides wireless network access |
| Hub | Broadcasts data to connected ports |
