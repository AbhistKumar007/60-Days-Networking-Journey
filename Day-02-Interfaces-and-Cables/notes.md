# 🚀 Day 2 — Interfaces and Cables

## 📌 Overview

Today I learned about **Network Interfaces and Cables**, which are the physical foundation of computer networking.

These components allow network devices to connect and communicate with each other.

---

# 🌐 1. What is a Network Interface?

A **Network Interface** is a hardware or virtual interface that allows a device to connect to a network.

A physical network interface is commonly provided by a **Network Interface Card (NIC)**.

### Examples

- Ethernet Interface
- Wireless Interface (Wi-Fi)
- Virtual Network Interface

### 💡 Remember

> Network Interface → Allows a device to connect to a network.

---

# 🔌 2. Ethernet Interface

An **Ethernet interface** is used for wired network communication.

It is commonly found on:

- Computers
- Servers
- Routers
- Switches
- Network appliances

Ethernet interfaces commonly use an **RJ45 connector** with copper Ethernet cables.

---

# 📶 3. Wireless Interface

A **Wireless Network Interface** allows devices to connect to a network using Wi-Fi without a physical Ethernet cable.

### Examples

- Laptop Wi-Fi adapter
- Smartphone Wi-Fi interface
- Wireless Access Point

### 💡 Remember

> Wireless Interface → Connects devices to a network using Wi-Fi.

---

# 🔗 4. RJ45 Connector

**RJ45** is the commonly used connector for twisted-pair Ethernet cables.

It is used to connect Ethernet cables to network interfaces.

### Commonly Used With

- PCs
- Switches
- Routers
- Servers
- Access Points

### 💡 Remember

> RJ45 → Common connector used with Ethernet cables.

---

# 🟦 5. Copper Ethernet Cables

Copper Ethernet cables transmit data using **electrical signals**.

Common Ethernet cable categories include:

- Cat5e
- Cat6
- Cat6a

### Advantages

- Affordable
- Easy to install
- Widely used in LANs
- Suitable for short and medium-distance connections

### 💡 Remember

> Copper Cable → Uses electrical signals to transmit data.

---

# 💡 6. Fiber Optic Cable

Fiber optic cables transmit data using **light signals** through optical fiber.

They are commonly used for:

- Long-distance communication
- High-speed network connections
- Data centers
- ISP networks

### Advantages

- High bandwidth
- Long transmission distances
- Resistant to electromagnetic interference
- Suitable for high-speed communication

### 💡 Remember

> Fiber → Uses light signals to transmit data.

---
